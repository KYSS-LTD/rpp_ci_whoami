# KyssProf

Профориентация через мини-игры. За одну смену на кухне, один день в бухгалтерии или один вылет дрона можно попробовать задачи профессии и понять, хочется ли заниматься ими дальше.

## Во что сыграть

| Игра | Что нужно сделать |
| --- | --- |
| Оператор БПЛА | Собрать квадрокоптер, снять с воздуха три сектора побережья и отметить мусор на снимках. В свободном режиме можно повторить отдельный этап, потренироваться на поле или пройти гонку. |
| Бухгалтер | Разобрать первичные документы, поработать с кассой, составить проводки, рассчитать зарплату, сверить выписку банка и собрать баланс. |
| Повар | Принять заказы, нарезать и пожарить продукты, собрать блюда и передать их в выдачу до того, как гости уйдут. |

В каталоге можно выбрать игру и сложность. В карточках «Повара» и «Закрытия квартала» есть короткие записи игрового процесса. Если для выбранной сложности есть сохранение, нажмите «Продолжить игру» и выберите «Продолжить с сохранения» или «Сбросить прогресс». Сброс запускает выбранную сложность с начала. Результаты в профиле, дипломы и достижения сохраняются.

В сюжетном вылете оператора БПЛА вернитесь к площадке H после съёмки. Когда дрон окажется над площадкой, нажмите «Посадить» или клавишу H. Дрон плавно снизится и сядет без повреждений от касания.

Завершённые уровни учитываются в профиле. Оцените понравившиеся игры от 1 до 5, чтобы интерес к задачам тоже повлиял на вклад игры в анализ профессий. Достижения открываются за игровые результаты.

Именной диплом можно скачать на экране завершённого уровня. После заезда или упражнения на поле портал показывает результат без диплома. Профиль, оценки и достижения хранятся в браузере. Диплом формируется по данным браузера, сервер результаты не заверяет.

## Быстрый запуск через Docker

Установите Docker с Compose и выполните команды из корня репозитория. В PowerShell используйте `Copy-Item .env.example .env` вместо `cp`.

```sh
cp .env.example .env
docker compose up -d --build
```

Откройте [каталог игр](http://localhost:3000/games). Чтобы выбрать другой локальный порт, измените `HTTP_PORT` в `.env` и снова выполните команду запуска.

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `SITE_DOMAIN` | `:80` | Адрес сайта для Caddy. Значение по умолчанию включает локальный HTTP. |
| `HTTP_PORT` | `3000` | Внешний HTTP-порт. |
| `HTTPS_PORT` | `3443` | Внешний HTTPS-порт. Caddy включает TLS, когда задано имя сайта. |

Для публичного запуска направьте DNS-запись домена на сервер и откройте входящие TCP-порты 80 и 443. Укажите в `.env` свой домен без схемы, например `SITE_DOMAIN=play.example.com`, а также `HTTP_PORT=80` и `HTTPS_PORT=443`. Caddy получит сертификат и перенаправит HTTP на HTTPS. Для игр отдельные домены и порты не требуются.

```sh
docker compose ps
docker compose logs -f portal proxy
docker compose down
```

## Разработка

Нужен Node.js 24. Портал работает на Next.js и React. Для 3D-игр используются Three.js и Vite.

```sh
cd web
npm ci
npm --prefix games/uav-operator ci
npm run dev
```

Портал откроется на [localhost:3000](http://localhost:3000). Перед запуском и производственной сборкой портал собирает тренажёр БПЛА. После правок в тренажёре выполните `npm run build:uav` и обновите страницу уровня. После правок в игре «Повар» выполните `npm run build:cooking`. Для отдельной разработки кухни есть `npm run dev:cooking`.

```sh
npm run check
npm run build
```

Первая команда проверяет типы, запускает тесты и линтер. Вторая собирает портал для запуска через `npm start`.

## Как устроен портал

Портал читает манифесты из реестра игр. Манифест описывает три сложности, запуск игры, карточку для каталога и связь с профессиями. Бухгалтерская игра работает как React-компонент. «Повар» и «Оператор БПЛА» запускаются в изолированных iframe. Игра сообщает о готовности, портал передаёт выбранный уровень, а после прохождения проверяет полученный результат.

| Где смотреть | Что там |
| --- | --- |
| [`web/app/`](web/app/) | Главная, каталог, экраны игр, достижения и «Мой анализ». |
| [`web/core/`](web/core/) | Реестр и контракт игр, проверка результатов, прогресс, анализ и дипломы. |
| [`web/games/`](web/games/) | Манифесты, исходники, тексты и тесты игр. |
| [`web/public/game-builds/`](web/public/game-builds/) | Сборки, которые загружает портал. |
| [`web/sdk/`](web/sdk/) | Мост для подключения игр во фрейме. |
| [`openspec/`](openspec/) | Требования, проектные решения и задачи. |

Чтобы подключить игру, добавьте модуль в `web/games/` и импортируйте его в [реестре](web/core/registry/index.ts). Для игры во фрейме пригодится [описание протокола](web/docs/game-bridge-protocol.md).

## Документация и OpenSpec

- [Платформа](openspec/specs/core-platform/spec.md) описывает каталог, выбор сложности, запуск уровня и работу браузерного хранилища.
- [Контракт игр](openspec/specs/game-module-contract/spec.md) и [спецификация iframe-моста](openspec/specs/game-iframe-bridge/spec.md) задают формат манифеста, обмен сообщениями и проверку результатов.
- [Анализ профессий](openspec/specs/profession-analysis/spec.md), [достижения](openspec/specs/achievements/spec.md) и [дипломы](openspec/specs/diplomas/spec.md) описывают правила платформы. Текущий интерфейс выдаёт PDF на экране результата.
- [Игровые спецификации](openspec/changes/) содержат проектные материалы «Повара» и «Закрытия квартала», а также план интерактивного обучения для бухгалтерской игры.
- [Устройство кухни](web/docs/cooking.md) и [маршрут обучения оператора](web/games/uav-operator/TRAINING.md) помогают разобраться в механике и проверках игр.
- [Стиль кода](CodeStyle.md) описывает правила проекта.
