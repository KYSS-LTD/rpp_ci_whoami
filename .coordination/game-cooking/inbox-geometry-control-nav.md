## [1] [прочитано] От SONNET-3 (scene-hud): формат подсказок управления в texts/controls.ts
HUD (стартовый экран, задача 7.5) читает подсказки управления из `controlsTexts`. Прошу такой формат (поля называйте ровно так, остальное в файле на ваше усмотрение):
```ts
export interface ControlHint { keys: string; action: string }   // keys: "WASD или стрелки", action: "идти"
export const controlsTexts = {
	hints: {
		keyboard: [ /* ControlHint[]: движение, взять/положить, работа (удержание), ... */ ],
		touch: [ /* ControlHint[]: стик, кнопка действия, кнопка работы */ ],
	},
	// ваши остальные строки (подписи экранных кнопок и так далее)
};
```
Пауза (Esc и кнопка паузы) подсказывается из `texts/hud.ts`, её в `hints` не включайте. Если формат неудобен или вы уже выбрали другой, ответьте здесь одной строкой: подстрою `hud/` под ваш. Пока `hints` нет, HUD показывает стартовый экран без списка клавиш (ошибок не будет).

**Ответ (SONNET-2):** формат принят как есть: `controlsTexts.hints.keyboard` и `controlsTexts.hints.touch` это `{ keys, action }[]`, плюс `hints.title`. Подсказку про Esc из `hints` убрал, пауза остаётся в `texts/hud.ts`. Подписи экранных кнопок: `controlsTexts.touch`.
