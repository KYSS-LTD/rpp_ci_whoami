# «Аэролаб» · Оператор БПЛА

Самостоятельная браузерная игра для школьников до 16 лет. Игрок собирает учебный дрон, проходит маршрут над пляжем и размечает снимок с воздуха. Каждый этап начинается с короткой интерактивной подсказки.

## Игровые этапы

1. **Сборка.** По карточке со схемой игрок размещает условные компоненты и соединяет отмеченные разъёмы. Схема различает их по форме и подписям. После проверки игра показывает ошибочные соединения и объясняет назначение платы, камеры и аккумулятора. Используем вымышленные детали и упрощённую схему.
2. **Полёт.** Игрок управляет дроном в трёхмерной бухте с клавиатуры или двух экранных джойстиков. Нужно сделать снимки трёх секторов с высоты 3-12 м, затем вернуться на площадку H и снизиться до 4 м. На мини-карте отмечены сектора, площадка и положение дрона.
3. **Анализ снимка.** Игрок выделяет объекты на отдельном учебном аэрофото и классифицирует их как бутылки, пакеты или банки. Для рамки можно провести пальцем, указать два угла или воспользоваться клавиатурой. Проверка учитывает положение и размер рамки, а подсказка отмечает область поиска.

## Запуск

Из папки `games/uav-operator` с Node.js 22.12 или новее запусти:

```sh
npm ci
npm run dev
```

Открой адрес, который выведет Vite. Для проверки на телефоне в той же сети используй адрес `Network` компьютера. Для графики требуется WebGL 2.

## Отдельный домен

Выполни `npm run build` и размести содержимое `dist/` на статическом HTTPS-хостинге. Для локальной проверки сборки выполни `npm run preview`. Шрифты, модели и код приложения обслуживаются вместе со сборкой. Игра хранит результаты завершённых этапов и личный рекорд в LocalStorage своего домена.

## Подключение к порталу

Скопируй `.env.example` в `.env` и укажи origin портала в `VITE_PORTAL_ORIGIN`, например `https://portal.example.com`. Настройки читаются при сборке. `VITE_DEBUG=true` включает сообщения разработчика в консоли.

После итоговой проверки аэрофото игра отправляет родительскому окну событие `whoami:game-completed`. Данные события содержат `version: 1`, `gameId: 'uav-operator'`, `score`, `maxScore: 300` и массив `stages`. В массиве три записи с полями `id`, `score`, `maxScore: 100`. Идентификаторы этапов идут в порядке `assembly`, `flight`, `survey`.

Встрой игру через `iframe` и установи обработчик до его загрузки. В обработчике проверь origin и окно отправителя, версию события, идентификатор игры и диапазон очков. Для самостоятельного запуска настройка портала необязательна.
