# Чек-лист моста iframe-игр (change game-iframe-bridge)

Последний прогон: 20.11.2026, dev-сервер Next.js 16.4.6 и `next start`, Chrome 1280x900 (светлая тема) и 390x844 (тёмная тема), тестовое имя "Тестер".

Встроенная панель браузера Claude Code блокирует запросы из изолированных фреймов (`ERR_BLOCKED_BY_CLIENT`), поэтому игру во фрейме проверяли в Chrome в безголовом режиме через протокол отладки, а панель использовали для страниц портала и запасного экрана.

## Перед проверкой

- [x] `npm run check` проходит: typecheck, 133 теста, проверка тире, линтер.
- [x] `npm run build` проходит, страницы `/games/city-builder/easy|medium|hard` собираются заранее.
- [x] `/game-builds/*` отдаёт `Access-Control-Allow-Origin: *` и `Content-Security-Policy: sandbox allow-scripts` в dev и в `next start`, `.wasm` приходит как `application/wasm`; страницы портала без `sandbox`.
