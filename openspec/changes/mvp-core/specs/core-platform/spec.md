# Spec Delta

## Purpose

Каркас сайта: лендинг с описанием проекта, экран игр, ввод имени и единый слой хранения в LocalStorage без регистрации и серверного аккаунта.

## ADDED Requirements

### Requirement: Landing page
Лендинг SHALL рассказывать о проекте, его пользе и геймификации и содержать кнопку перехода к списку игр.

#### Scenario: Visitor opens the landing page
- **WHEN** посетитель открывает корневой адрес сайта
- **THEN** отображается описание проекта и кнопка перехода к играм

#### Scenario: Button opens the games screen
- **WHEN** посетитель нажимает кнопку перехода к играм
- **THEN** открывается экран со списком игр

### Requirement: Games screen
Экран игр SHALL отображать все зарегистрированные игры с их уровнями и статусом прохождения каждого уровня для текущего пользователя.

#### Scenario: Games are listed with progress
- **WHEN** пользователь открывает экран игр
- **THEN** каждая зарегистрированная игра показана с тремя уровнями и отметкой о прохождении

### Requirement: Name input
Перед первым прохождением пользователь SHALL ввести имя, которое используется в дипломах. Имя SHALL сохраняться в LocalStorage.

#### Scenario: First visit requires a name
- **WHEN** в LocalStorage нет сохранённого имени и пользователь начинает уровень
- **THEN** платформа запрашивает имя перед запуском уровня

#### Scenario: Saved name is reused
- **WHEN** имя уже сохранено в LocalStorage
- **THEN** запрос имени не показывается повторно

#### Scenario: Empty name is rejected
- **WHEN** пользователь отправляет пустое имя или только пробелы
- **THEN** платформа показывает сообщение об ошибке и не сохраняет имя

### Requirement: No account registration
Платформа SHALL работать без регистрации и авторизации. Все пользовательские данные SHALL храниться только в LocalStorage браузера.

#### Scenario: No login is requested
- **WHEN** пользователь пользуется сайтом
- **THEN** ни одна страница не требует логина, пароля или email

### Requirement: Storage layer
Платформа SHALL обращаться к LocalStorage через единый модуль хранения. Чтение и запись SHALL быть обёрнуты в обработку ошибок, чтобы сайт работал при недоступном LocalStorage.

#### Scenario: Storage is unavailable
- **WHEN** LocalStorage недоступен или заблокирован браузером
- **THEN** сайт открывается, прохождение работает в памяти текущей сессии, и пользователь видит предупреждение о том, что результаты не сохранятся

### Requirement: Reset progress
Пользователь SHALL иметь возможность сбросить результаты прохождения по всем играм и профессиям. Сброс SHALL требовать подтверждения.

#### Scenario: Reset clears results
- **WHEN** пользователь подтверждает сброс
- **THEN** результаты прохождения, ачивки, дипломы и анализ профессий удаляются, имя сохраняется

#### Scenario: Reset is cancelled
- **WHEN** пользователь отказывается от сброса в окне подтверждения
- **THEN** данные не изменяются
