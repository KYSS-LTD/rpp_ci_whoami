# Spec Delta

## Purpose

Именные дипломы о прохождении игр. Диплом выдаётся по каждой игре на каждой сложности и содержит имя пользователя, очки, максимум очков, сложность и рейтинг прохождения.

## ADDED Requirements

### Requirement: Diploma per completed level
Диплом SHALL выдаваться за каждый завершённый уровень (`completed=true`) каждой игры. Диплом содержит имя пользователя, название игры, уровень сложности, набранные очки и максимум очков.

#### Scenario: Diploma is issued after completion
- **WHEN** пользователь завершает уровень с результатом `completed=true`
- **THEN** диплом за этот уровень появляется в списке дипломов с именем пользователя, очками и сложностью

#### Scenario: Abandoned level has no diploma
- **WHEN** уровень не завершён
- **THEN** диплом не выдаётся

### Requirement: Rating on diploma
Каждый диплом SHALL содержать рейтинг прохождения, вычисленный по доле набранных очков от максимума. Рейтинг SHALL принимать одно из значений: `bronze`, `silver`, `gold`.

#### Scenario: Rating thresholds
- **WHEN** доля очков меньше 50 процентов
- **THEN** рейтинг `bronze`
- **WHEN** доля очков от 50 до 79 процентов включительно
- **THEN** рейтинг `silver`
- **WHEN** доля очков 80 процентов и выше
- **THEN** рейтинг `gold`

### Requirement: Diploma stores the name at issue time
Диплом SHALL сохранять имя пользователя на момент выдачи. Последующая смена имени не меняет уже выданные дипломы.

#### Scenario: Name changed after issue
- **WHEN** пользователь меняет имя после получения диплома
- **THEN** старый диплом сохраняет прежнее имя

### Requirement: Certificate for a score on a level
Пользователь SHALL иметь возможность получить сертификат о прохождении уровня с указанием очков, максимума и сложности, в виде файла для сохранения или печати.

#### Scenario: Certificate is downloaded
- **WHEN** пользователь нажимает кнопку сертификата у диплома
- **THEN** браузер предлагает сохранить файл сертификата с именем, игрой, сложностью и очками

### Requirement: Diploma list
Платформа SHALL показывать все выданные дипломы, сгруппированные по игре.

#### Scenario: Diplomas are grouped by game
- **WHEN** пользователь открывает список дипломов
- **THEN** дипломы показаны по играм, внутри игры по уровням сложности

### Requirement: Certificate limits
Сертификат SHALL формироваться только на устройстве пользователя из данных LocalStorage. Платформа SHALL явно указывать на странице, что данные не проверяются сервером.

#### Scenario: Notice is shown
- **WHEN** пользователь открывает страницу дипломов
- **THEN** отображается пометка о том, что результаты хранятся локально и не подтверждены сервером
