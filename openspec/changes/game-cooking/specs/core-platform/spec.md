# Spec Delta

## MODIFIED Requirements

### Requirement: Reset progress
Пользователь SHALL иметь возможность сбросить результаты прохождения по всем играм и профессиям. Сброс SHALL требовать подтверждения.

#### Scenario: Reset clears results
- **WHEN** пользователь подтверждает сброс
- **THEN** результаты прохождения, ачивки, дипломы, анализ профессий и сохранённые блоки данных игр удаляются, имя сохраняется

#### Scenario: Reset is cancelled
- **WHEN** пользователь отказывается от сброса в окне подтверждения
- **THEN** данные не изменяются

#### Scenario: Game hints return after reset
- **WHEN** пользователь сбросил результаты, а затем открыл уровень игры, которая хранит прогресс подсказок в блоке данных игры
- **THEN** игра получает старт без блока данных и показывает подсказки заново
