# Spec Delta

## MODIFIED Requirements

### Requirement: Games screen
Экран игр SHALL отображать все зарегистрированные игры лентой карточек. Карточка показывает обложку, название, описание, метку формата и метку "В разработке", если они заданы в манифесте, число пройденных уровней из трёх для текущего пользователя и кнопку "Играть". Уровни и их статус показываются в карточке игры. При пустом реестре SHALL показываться пустое состояние.

#### Scenario: Games are listed with progress
- **WHEN** пользователь открывает экран игр
- **THEN** каждая зарегистрированная игра показана карточкой с числом пройденных уровней из трёх и кнопкой "Играть"

#### Scenario: Empty registry
- **WHEN** в реестре нет ни одной игры
- **THEN** экран игр показывает пустое состояние с пояснением

## ADDED Requirements

### Requirement: Game format filter
Если в библиотеке есть игры хотя бы двух форматов, экран игр SHALL показывать фильтр по формату с вариантом "Все". Выбор формата MUST оставлять в ленте только игры этого формата.

#### Scenario: Filter by format
- **WHEN** в библиотеке есть игры форматов 2D и 3D и пользователь выбирает 3D
- **THEN** в ленте остаются только игры формата 3D, а выбор "Все" возвращает все игры

#### Scenario: Single format hides the filter
- **WHEN** у всех игр библиотеки один формат или формат не задан
- **THEN** фильтр по формату не показывается

### Requirement: Game card
По кнопке "Играть" экран игр SHALL открывать карточку игры поверх ленты: превью из игры, название, метки, краткую сводку (или описание, если сводки нет), примерное время уровня, если оно задано, и связанные профессии.

#### Scenario: Card shows the summary
- **WHEN** пользователь нажимает "Играть" у игры со сводкой, временем уровня и профессиями
- **THEN** открывается карточка игры с этой сводкой, временем уровня и названиями профессий

#### Scenario: Description replaces a missing summary
- **WHEN** у игры нет сводки
- **THEN** карточка показывает описание игры

### Requirement: Preview slideshow
Превью в карточке игры SHALL само сменять кадры из манифеста через несколько секунд и давать переключить кадр вручную. Если пользователь просит уменьшить движение (`prefers-reduced-motion`), кадры MUST NOT сменяться сами. Без кадров показывается обложка-заглушка.

#### Scenario: Frames change automatically
- **WHEN** у игры несколько кадров превью и карточка открыта
- **THEN** через несколько секунд показывается следующий кадр

#### Scenario: Frame selected manually
- **WHEN** пользователь выбирает кадр точкой под превью
- **THEN** показывается выбранный кадр

#### Scenario: Reduced motion stops the slideshow
- **WHEN** в системе включено уменьшение движения
- **THEN** кадры не сменяются сами

#### Scenario: No frames
- **WHEN** в манифесте нет кадров превью
- **THEN** вместо превью показывается обложка-заглушка

### Requirement: Difficulty selection
Карточка игры SHALL показывать три уровня сложности со статусом "Пройден" или "Не пройден" и кнопку "Начать", которая ведёт на страницу выбранного уровня. По умолчанию MUST быть выбран первый непройденный уровень, а если пройдены все, то первый уровень.

#### Scenario: First open level is preselected
- **WHEN** пользователь прошёл уровень easy и открывает карточку игры
- **THEN** выбран уровень medium, а "Начать" ведёт на `/games/<gameId>/medium`

#### Scenario: Another level is chosen
- **WHEN** пользователь выбирает уровень hard
- **THEN** "Начать" ведёт на `/games/<gameId>/hard`

#### Scenario: All levels completed
- **WHEN** все три уровня игры пройдены
- **THEN** выбран уровень easy

### Requirement: Game card closing
Карточка игры SHALL закрываться кнопкой закрытия, клавишей Escape и нажатием на фон за карточкой. После закрытия пользователь возвращается к ленте.

#### Scenario: Close by button, Escape or backdrop
- **WHEN** пользователь нажимает кнопку закрытия, клавишу Escape или фон за карточкой
- **THEN** карточка закрывается, лента игр остаётся на месте

### Requirement: Rating in game card
Оценка игры от 1 до 5 SHALL выставляться в карточке игры и сопровождаться сообщением о результате: оценка сохранена или её можно поставить только после прохождения уровня.

#### Scenario: Rating before any completed level
- **WHEN** пользователь выбирает оценку в карточке игры, у которой нет пройденных уровней
- **THEN** оценка не сохраняется и показывается сообщение, что оценить можно после прохождения уровня

#### Scenario: Rating after a completed level
- **WHEN** пользователь выбирает оценку в карточке игры после прохождения уровня
- **THEN** оценка сохраняется и показывается сообщение "Оценка сохранена"
