# Spec Delta

## ADDED Requirements

### Requirement: Level failure fallback
Если уровень игры упал при отрисовке, сообщил об ошибке или не загрузился вовремя, платформа SHALL показать запасной экран с сообщением, кнопкой повтора уровня и ссылкой в библиотеку игр. Шапка, навигация и данные пользователя MUST оставаться рабочими.

#### Scenario: React level throws while rendering
- **WHEN** компонент уровня React-игры выбрасывает исключение при отрисовке
- **THEN** вместо уровня показывается запасной экран, а шапка сайта и навигация работают

#### Scenario: Retry after failure
- **WHEN** пользователь нажимает кнопку повтора на запасном экране
- **THEN** уровень запускается заново с начала
