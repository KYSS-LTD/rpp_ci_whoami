# profession-analysis Specification

## Purpose

Личная страница анализа, которая по результатам игр и оценкам пользователя показывает, какие профессии ему подходят больше всего. Расчёт выполняется на устройстве пользователя.

## Requirements

### Requirement: Rating of a played game
Пользователь SHALL иметь возможность оценить игру оценкой от 1 до 5 после прохождения хотя бы одного уровня этой игры. Оценка SHALL сохраняться в LocalStorage.

#### Scenario: Game is rated
- **WHEN** пользователь выбирает оценку от 1 до 5 для игры
- **THEN** оценка сохраняется и учитывается в анализе

#### Scenario: Out-of-range rating is rejected
- **WHEN** передано значение вне диапазона 1-5
- **THEN** оценка не сохраняется

### Requirement: Profession score calculation
Платформа SHALL рассчитывать балл каждой профессии как сумму произведений весов профессии в играх на долю очков пользователя по уровню и оценку игры, нормированную к сумме весов.

#### Scenario: Score is computed from completed levels
- **WHEN** пользователь завершил несколько уровней разных игр
- **THEN** балл каждой профессии рассчитан по формуле и отображается в процентах

#### Scenario: No completed levels
- **WHEN** пользователь не завершил ни одного уровня
- **THEN** анализ не рассчитывается и отображается сообщение о необходимости пройти хотя бы одну игру

### Requirement: Ranking of professions
Личная страница SHALL показывать профессии, отсортированные по баллу, и выделять наиболее подходящую.

#### Scenario: Top profession is highlighted
- **WHEN** анализ рассчитан
- **THEN** профессия с наибольшим баллом показана первой и отмечена как наиболее подходящая

### Requirement: Analysis is local
Расчёт анализа SHALL выполняться только на устройстве пользователя, без отправки данных на сервер.

#### Scenario: No network request for analysis
- **WHEN** пользователь открывает личную страницу анализа
- **THEN** расчёт выполняется локально и сетевой запрос с результатами не отправляется

### Requirement: Analysis page content
Личная страница SHALL показывать имя пользователя, пройденные игры с уровнями, полученные ачивки и результат анализа профессий.

#### Scenario: Personal page is opened
- **WHEN** пользователь открывает личную страницу
- **THEN** страница содержит имя, список пройденных игр, ачивки и ранжированный список профессий
